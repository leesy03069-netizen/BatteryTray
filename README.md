# 外设电量 BatteryTray（测试版）

Windows 任务栏直接显示无线鼠标、键盘的电量数字。绿色 M 是鼠标，蓝色 K 是键盘；不必打开官方驱动才能看电量。

## 目前做到什么

- 两个独立托盘数字图标；点击打开圆角详情卡片。
- 默认约每 3 秒查询一轮（查询耗时额外计入），可在设置中选择 2–60 秒。
- 充电小闪电、20% / 10% 分档提醒，当前进程内避免重复提醒。
- 暂未响应时变灰并保留最后读数；无法区分设备休眠、关机或掉线。
- 中文设备设置：扫描厂商 HID 接口，选择接收器，修改名称、VID/PID、Usage Page；保存后下一轮应用。
- 本地运行，无账号、无遥测、无自动上传设备信息。

## 支持范围：请先看这里

**这不是万能电量读取器。改 VID/PID 不等于适配任意设备。**

| 协议 | 实测接收器 | 验证范围 |
|---|---|---|
| ATK / Compx 鼠标，Report 08、命令 04 | `373B:10C9`，用户设备为 ATK A9 Plus | 本机真实电量响应；解析字段与 ATK HUB 的 Compx 解析代码对照一致 |
| Beiying 键盘，Report 13、命令 4A | `3554:FA09`，用户称其为狼蛛 F87 Pro | 本机真实电量及充电标记响应；尚未与官方界面同步对照 |

注意：`3554:FA09` 在参考项目设备表中标注为 **VXE V87pro 接收器**，与用户提供的键盘型号不同。这里按接收器 ID 和已验证协议适配，不据此宣称支持所有狼蛛 F87 Pro。不同批次、接收器、固件可能不同。

- **已验证**：上表两套具体接收器及当前固件，Windows 11 x64。
- **可能兼容，未验证**：确知使用同一请求、响应格式及校验方式的其他接收器，可修改设置后自行测试。
- **尚未支持**：协议不同的设备、通用蓝牙电量、罗技 HID++、雷蛇等其他私有协议。需要增加独立驱动适配器。
- 发布包面向 Windows x64，未在另一台无 Python 的干净电脑上验证；Windows 10 尚未实测。

## 普通用户如何使用

1. 下载并解压整个 `BatteryTray-Windows-x64.zip`，保留 `_internal` 文件夹。
2. 双击 `BatteryTray.exe`。无需另装 Python 或官方驱动。
3. 图标可能被 Windows 放进隐藏托盘，可在 Windows 设置中开启常显。
4. 左键打开详情；右键选择“设备设置…”或“退出”。

本测试版不自动添加开机启动，不修改鼠标 DPI、键盘灯效、按键映射或固件；没有安装器。退出后删除解压目录即可移除程序。用户配置保存在 `%LOCALAPPDATA%\BatteryTray\devices.json`，不随解压包一起移动。

## 接入其他接收器

**先确认协议，再选设备；不要凭品牌猜协议。**

1. 在官方驱动、公开协议文档或已有开源实现中，核实接收器使用哪个内置协议。
2. 右键托盘 → 设备设置 → 扫描接收器。扫描仅枚举，不发送命令。
3. 在鼠标或键盘槽位选择接口，自动填写 VID/PID 和 Usage Page。名称可自行修改。
4. 核对协议说明，保存并应用。未收到有效响应时显示 `--`，不要反复更换未知协议试探。
5. 与官方驱动对比未充电、充电和拔线后读数，再报告兼容情况。

目前固定两个槽位，每槽一个协议：鼠标槽用 Compx，键盘槽用 Beiying。不是任意命令编辑器；不能直接上传 JS 插件。新协议由开发者在 `profiles.py` 中增加驱动与严格解析，并补测试。

四位十六进制配置示例见 `devices.example.json`。不含 `0x`、空格；格式错误不会自动修正。

## 电量准确性

显示的是 **设备自己上报的估算值**，不是软件测量电池容量。充电时可能从 80% 跳到 90%，拔线后又回 80%；这不代表短时间充入了 10%。目前只验证了鼠标字段解析与官方代码一致，不能保证电池估算校准准确，也没有完成插拔全过程的官方 UI 同步对照。请以大致余量和低电量提示为参考。

## 无法识别怎么办

- 确认已插正确接收器、设备已唤醒，并检查是否切到了蓝牙模式。
- 检查设置中 VID/PID、Usage Page 是否匹配。扫描结果中出现不代表协议兼容。
- 同一型号可能用不同代工方案；请提供品牌型号、连接方式、接收器 VID/PID、固件版本、官方驱动能否显示电量。不要公开设备序列号、完整 HID 路径或个人日志。
- 若暂未响应，软件最多保留上次数据并变灰，不伪造 0% 或 100%。

## 从源码运行与构建

```text
python -m pip install -r requirements.txt
python -m unittest discover -s tests
python app.py
python -m PyInstaller --noconfirm --clean --windowed --onedir --name BatteryTray --hidden-import pystray._win32 app.py
```

代码依赖 Windows、Tk、hidapi、Pillow、pystray。不要同时安装会与 `hidapi` 的 `import hid` 冲突的另一个 `hid` 包。
